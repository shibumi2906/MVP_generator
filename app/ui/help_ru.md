### Что здесь можно сделать
Опишите будущий продукт обычными словами. Генератор подготовит **черновик технического
задания и план разработки**: требования, архитектуру, данные, API и задачи.
Работающее приложение и исходный код нужно будет создавать отдельно по этому плану.

### 1. Заполните описание
Обязательно только поле **«Идея продукта»** — минимум 10 символов. Для полезного результата
напишите: **кто пользователь → какая у него проблема → что он сможет сделать**.
Можно писать по-русски. Не вставляйте API-ключи, пароли и реальные данные клиентов:
в режиме OpenAI описание отправляется модели.

| Поле | Что написать | Пример |
| --- | --- | --- |
| Идея продукта | Проблема и 2–3 главные возможности | Репетитор хранит учеников и планирует занятия вместо блокнота |
| Для кого | Кто будет пользоваться | Частные репетиторы без помощника |
| Сценарий работы | Действия пользователя по порядку | Добавить ученика → назначить занятие → открыть расписание |
| Ограничения | Срок, команда и что исключить | Один человек, неделя, без платежей |
| Технологии | Предпочтительный набор инструментов | Можно оставить предложенный вариант |

Если не знаете технические детали, оставьте дополнительные поля пустыми.
Кнопка **«Заполнить пример»** подставит готовое описание для знакомства с формой.
Она заменит текст в полях, но сама генерацию не запускает.

### 2. Нажмите «Создать план разработки»
Дождитесь результата под формой. В режиме **OpenAI** каждый запуск расходует токены.
В режиме **Демо** показывается один общий пример, который не адаптируется к вашей идее.
После успеха результат сохраняется автоматически в разделе **«Сохранённые планы»** слева.
Нажмите название плана, чтобы открыть его снова без новой генерации.

### 3. Проверьте результат и скачайте документы
| Вкладка | Что проверить |
| --- | --- |
| Требования | Правильно ли поняты проблема, аудитория и границы первой версии |
| Архитектура | Из каких частей будет состоять приложение и как они связаны |
| Данные | Какие сущности нужно хранить, их поля и связи; например, ученик и занятие |
| API | Какие запросы должен поддерживать сервер; раздел для разработчика |
| План работ | В каком порядке реализовать функции и как проверить готовность |
| Допущения | Что модель предположила сама и что вам нужно уточнить |

Сначала прочитайте **«Требования»** и **«Допущения»**. Если идея понята неверно,
уточните поля формы и создайте новый план — это отдельный запрос с расходом токенов.
Проверка структуры подтверждает согласованность ссылок между документами;
качество продуктовых решений нужно оценить самостоятельно.

Нажмите **«Подготовить ZIP»**, затем **«Скачать документы»**.
Архив содержит текстовые документы Markdown, исходники схем Mermaid и JSON с данными плана.
Его можно передать разработчику или открыть в редакторе и использовать как основу для реализации.
Готовой программы в архиве нет.

### Токены и дневной лимит
Токены — единицы текста, которые модель читает и создаёт; это не количество запросов.
Лимит приложения — **150 000 входных и выходных токенов в день**. Он общий для всех
генераций в этом приложении и сбрасывается в **00:00 по времени Израиля**.
Счётчик слева включает расход и резерв для незавершённых запросов, сохраняется после
перезапуска и не включает запросы из других приложений или расход до включения учёта.
При ошибке без подтверждённого расхода резерв остаётся учтённым до конца дня.

### Если что-то не получилось
- **Слишком короткая идея:** опишите продукт подробнее, минимум 10 символов.
- **Истекло время ожидания:** результат не сохранён. Проверьте историю и счётчик,
  сократите описание и повторите позже; новый запуск может снова расходовать токены.
- **Дневной лимит исчерпан:** дождитесь полуночи по Израилю. Перезапуск лимит не обнуляет.
- **OpenAI отклонил запрос:** проверьте ключ, доступ к модели и настройки сервера.
- **Лимит или квота OpenAI:** проверьте баланс и ограничения своего API-аккаунта.
- **Не удалось проверить документы:** модель вернула несогласованный черновик.
  Упростите первую версию до нескольких основных функций и повторите запрос.
- **Сервер недоступен:** API должен работать вместе с интерфейсом; одного открытого
  окна браузера недостаточно. Попросите запустить приложение заново.

Если сохранённый план помечен **«Происхождение неизвестно»**, это старый результат:
его можно открыть и скачать, но источник и согласованность не подтверждены.
